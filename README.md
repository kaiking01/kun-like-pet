# Kun Like 桌宠 🐱

> 一只会躲猫猫、捉蝴蝶、打盹做梦的 3D 可爱猫咪桌宠，还会到点变身巨猫咚咚敲屏提醒你：**该喝水啦！**

纯 CSS + 原生 JS 实现，无任何依赖。奶油色小猫咪蹲在花瓶旁边，自带 3D 透视视角与丝滑动作引擎，适合放在浏览器角落陪伴办公的每一天。

## ✨ 功能特性

- 🏺 **场景小剧场**：蓝色小花瓶 + 三朵摇摆的花朵（粉/黄/紫）+ 猫咪的小水碗
- 🎭 **真猫习性的行为**（自动随机上演）
  - **躲猫猫**：先蹲下、扭扭屁股，再溜到花瓶后面，时不时探出小脑袋回头看你
  - **捉蝴蝶**：蝴蝶 3D 拍翅绕着花丛飞，猫咪歪头盯着、挥爪扑蝶
  - **打盹**：靠着花瓶睡觉，吹鼻涕泡泡、飘 zZz、梦见大餐 🍗
  - **舔毛洗脸**：抬起爪子舔舔、再揉揉脸
  - **打哈欠**：张大嘴、仰头，超有感染力
  - **弓背伸懒腰**：前爪前伸、后背拱起，标准的猫式拉伸
  - **歪头好奇** / **慢眨眼卖萌**（"喜欢你哦～"）
  - **喝水提醒**：到点先自己跑去水碗"咕咚咕咚"，然后**变身巨猫**占大半个屏幕，伸爪在屏幕上咚咚敲击，提醒你喝水
- 🎥 **真 3D 效果**：猫咪头部是**多层 3D 结构**（正面/侧面/脑后），转头时能看到头的侧面和脑后，不是纸片平移；蝴蝶远近穿梭、地面影子随身高变化
- 🖱️ **跟着你的鼠标**：移动鼠标时猫咪会**转头看你**，眼睛也跟随；3 秒不动就转回前方
- 👀 **活灵活现**：左眼右眼**不对称地眨**（还会慢眨眼、偶尔眯眼）、鼻子嗅嗅、胡子偶尔抖动、耳朵抽动、尾巴慢摇；动作带**重量感**——起跳前先蹲、落定有回弹
- 💬 **纯文字卖萌**：无语音，所有台词用气泡文字呈现，画面请自行脑补 ✨
- 🖱️ **交互**：点击互动（爱心 + 卖萌）、拖动随意摆放、悬停可设置/隐藏

## 🚀 快速开始

**方式一：直接打开**

用浏览器打开 `index.html` 即可，猫咪出现在右下角。无需安装任何东西。

**方式二：本地服务器（可选）**

```bash
python -m http.server 8080
# 或
npx serve .
```

然后访问 http://localhost:8080

## 🎮 操作说明

| 操作 | 效果 |
|---|---|
| 点击猫咪 | 开心蹦跳 + 爱心飘起 + 随机卖萌台词 |
| 拖动猫咪 | 把它放到屏幕任意位置 |
| 悬停 → ⚙ | 打开设置：提醒开关 / 间隔（30/45/60/90 分钟）/ 重置位置 / 隐藏 |
| 悬停 → × | 暂时藏起来（右下角"🐾 小猫咪回来"可召回） |

## 🧩 技术要点

- **过渡驱动动画**：姿势（走位/转头/倾斜/压扁）全部通过 CSS `transition` 平滑插值，任意两个动作之间切换都丝滑，杜绝"生硬跳变"
- **CSS 3D**：`perspective` + `preserve-3d` + `translateZ` 分层，蝴蝶用 `perspective(400px) rotateY()` 实现 3D 拍翅
- **状态机**：`runSeq()` 序列引擎按时间轴驱动姿势变化，可随时取消并平滑回到原位
- **零依赖**：无框架、无构建、无外部资源，单文件即可运行
